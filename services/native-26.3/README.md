# Native Minecraft 26.3 adapter

`npm run setup:native` installs pinned, SHA256-checked source overlays into `node_modules/.companion-native/26.3`. Bootstrap runs this automatically after `npm ci --ignore-scripts`. Released dependency packages and their manifests remain intact. No package lifecycle scripts or moving Git branches are executed. The source lock records all base versions, source commits, paths and download hashes. `npm ci` removes the adapter; rerun setup afterward.

The preloader validates every overlay before loading it. It adds exact-version data to the existing minecraft-data loader and redirects this process's CommonJS package exports to the assembled native stack. No system environment variables, Minecraft files, authentication stores or public listeners are changed. ESM imports retain the original object identity. Account workers load the same stack. If the adapter is unavailable or its integrity check fails, 26.3 falls back to the bridge and its existing projection restrictions. `COMPANION_NATIVE_PROTOCOL=off` explicitly selects that fallback for diagnosis.

Sources are MIT-licensed Prismarine projects, including DallasCarraher's pinned native 26.3 branches. Copied npm packages retain their licenses. Data source: [minecraft-data PR1301](https://github.com/PrismarineJS/minecraft-data/pull/1301); protocol source: [node-minecraft-protocol PR1538](https://github.com/PrismarineJS/node-minecraft-protocol/pull/1538). These are locally validated adaptations, not a claim of upstream release or exhaustive 26.3 support.

Local official 26.3 survival verification (`node scripts/test-native-game.mjs`) covers protocol777 spawn, physics, exact inventory, pathfinding, vanilla crafting, approved digging/pickup, six-block full-cube construction with checkpoint interruption/resume, and paused reconnect. It verifies the official server SHA1, private Java executable, EULA receipt and dedicated paths, and awaits server cleanup. The fixture seeds materials through its own console; the bot uses normal survival client packets. It never targets a Realm.

Mojang's official 26.3 server-generated registry/block reports matched all 1,286 block IDs, state ranges/default states and all 1,658 item IDs in this lock. Component reports exposed17 upstream stack-size errors (cushions and straw beds); the lock's explicit stack corrections fix them. Those reports are generated locally from the user's accepted test-server runtime, not bundled proprietary server assets. A separate passive licensed Realm probe passed protocol777/26.3, no translation and no kick over 869 physics ticks. This does not establish Realm gathering or construction.

Remaining boundaries: new 26.2/26.3 block collision/hardness/crafting metadata and some uncommon item component codecs are incomplete upstream. Newly introduced materials are observable by their native identities, but destructive gathering and construction with them are blocked pending validation. Their raw-resource plans carry an unresolved warning. Existing materials remain supported. Oriented/multiblock placements, scaffolding, clearing and inventory resupply still need separate tested controllers. The adapter must not be described as exhaustive production support.
