# Community code of conduct

We welcome contributors across experience levels, backgrounds and identities.
Treat people with respect. Critique code and evidence, not the person.

Expected behavior includes patient explanations, constructive feedback, accurate
credit and respect for privacy. Harassment, discriminatory abuse, threats,
sexualized attention, doxxing and deliberate disruption are not acceptable.

This applies to project issues, reviews, discussions and project-run events.
Maintainers may edit or remove harmful content and warn, restrict or exclude
participants proportionately. They should explain decisions privately when safe,
consider context and allow a good-faith appeal.

Report conduct concerns privately to the repository owner through their public
GitHub profile contact, or use GitHub's Report content feature if no private
contact is available. Do not publish sensitive details in an issue. There is no
dedicated staffed moderation team or promised response time.
