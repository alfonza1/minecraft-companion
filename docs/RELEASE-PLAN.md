# Waypoint release work

Waypoint is the agent platform identity. Minecraft Companion remains the first
environment and the existing local application/data identity. This avoids breaking
installed shortcuts, authentication caches, projects, or launcher updates.

## Audit (2026-11-01)

- One Node runtime owns one Mineflayer body. Deterministic safety and skills run
  below an event-driven planner; there is no autonomous inference polling loop.
- Zod validates plans and actions. Runtime cancellation, task stacks, reservations,
  observed inventory, blueprint approvals and SQLite checkpoints already exist.
- React/Vite dashboard, Fastify HTTP/WebSocket API, local Python speech, Windows
  WebView2 launcher. Preserve these, upstream `src/` MCP and existing recipes.
- Codex, Claude Code and OpenCode integrations exist. A direct local Ollama route
  is missing. Optional provider accounts are not part of the free software license.
- Native 26.3 protocol adapter is pinned with file checksums. Other environments,
  multi-body agent teams, general cave mining and unrestricted builds do not exist.
- Windows DPAPI protects tokens; the desktop/global hotkey/speech bootstrap is
  Windows-specific. Portable browser/offline planning is feasible; full macOS/Linux
  Realm authentication and desktop voice must not be advertised as supported.
- No public site, contributor workflow, release automation or portable quickstart.
- Repository is already public. Original Apache-2.0 and NOTICE must be preserved.
- Existing documentation contains workstation-specific paths and test anecdotes.
  Public documentation must distinguish reproducible results from local history.

## Design direction

Your supplied reference informs the near-black canvas, large geometric sculpture,
editorial whitespace, subtle surface lighting and clipped white controls. Original
Waypoint design uses obsidian #0b0e10, mineral #a9bbb7, chalk #f4f5ef, rose #ed7da7,
and glacial teal #68d4cc. Display: locally hosted Space Grotesk; body: system sans;
technical labels: monospace. The signature is an interactive spatial graph of the
agent lifecycle, explicitly labeled an explanatory visualization, not live play.

No invented ratings, testimonials, benchmark wins or public access to local state.
Launch as an experimental open-source release, not a claim of consumer maturity.

## Positioning refinement

The homepage leads with “Minecraft survival. Better together.” and immediately
describes an AI teammate. Gathering, mining, crafting, building, natural voice and
shared work remain visible alongside the open-source agent engineering.

The abstract voxel sculpture was replaced after owner feedback with original
Minecraft survival teammate concept artwork: two cooperative characters, supplies,
ore and a cottage. It is labeled illustration, never live gameplay.
