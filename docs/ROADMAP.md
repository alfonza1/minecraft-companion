# Roadmap

## Implemented foundation

One-body lifecycle; structured plans; deterministic bounded survival skills;
real inventory; approved blueprint construction; task interruption and checkpoints;
shared resource assignments; local memory; Windows voice; selectable providers.

## Release priorities

- Secure native credential adapters and voice installation on macOS/Linux.
- Signed desktop installers and wider clean-machine validation.
- Dependency advisory reduction without breaking the protocol stack.
- More real survival fixtures and accessible setup improvements.
- Better model/hardware guidance and opt-in reproducible comparisons.

## Research, not shipped

General cave/branch mining, broader build supply chains, unrestricted terrain
preparation, a second execution environment and coordinated multiple embodied agents.
There are no promised delivery dates. See CONTRIBUTING.md for scoped entry points.
