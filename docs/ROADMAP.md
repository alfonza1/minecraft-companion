# More worlds, built together

Waypoint's direction is an AI gaming companion people enjoy playing and talking
with. Minecraft Survival is the first and only playable integration. Future games
are community proposals and research until real connections, actions and tests
exist. There are no promised release dates or fabricated popularity rankings.

## Implemented foundation

One-body lifecycle; structured plans; deterministic bounded survival skills;
real inventory; approved blueprint construction; task interruption and checkpoints;
shared resource assignments; local memory; Windows voice; selectable providers.

The shared workspace now includes missions, activity, resource accounting,
persistent assistance decisions and companion conversation. Profiles, real
background-work modes, optional retained moments and communication controls give
the companion a consistent presence without artificial relationship progression.

A validated game-observation registry supports Minecraft and a non-playable
strategy fixture for development tests. This is a narrow extensibility boundary,
not a claim that Minecraft's action executor can run another game.

## Release priorities

- Secure native credential adapters and voice installation on macOS/Linux.
- Signed desktop installers and wider clean-machine validation.
- Dependency advisory reduction without breaking the protocol stack.
- More real survival fixtures and accessible setup improvements.
- Better model/hardware guidance and opt-in reproducible comparisons.
- Wider tests of task ownership, concurrent help responses and resource provenance.
- More accessible workspace flows and clearer source/uncertainty presentation.

## Research, not shipped

| Direction | Useful next experiment |
| --- | --- |
| Minecraft Survival | Safer cave/branch mining, broader crafting and construction supply chains |
| Core architecture | Extract an action-executor seam when a second legitimate game validates its needs |
| Companion memory | Relevant retrieval and user-reviewable summaries with source attribution |
| Natural voice | Measured end-to-end latency, richer turn-taking and interruption reliability |
| New games | A permitted integration and one small cooperative objective before broad support |
| Multi-agent play | Explicit body ownership, coordination and failure isolation in a controlled fixture |
| Evaluation | Repeatable model/hardware comparisons and real long-horizon survival scenarios |
| Community tooling | Better proposal triage, contributor examples and reproducible bug reports |

General unrestricted exploration, universal video-to-build copying, human-level
game mastery and memory/ability transfer between games are not implemented.

Use the [game proposal template](https://github.com/alfonza1/minecraft-companion/issues/new?template=game-integration.yml)
or a focused capability issue. The issue tracker is the current public community
system; there is no independent voting service. See [CONTRIBUTING](../CONTRIBUTING.md)
and [game adapters](GAME-ADAPTERS.md) for practical entry points.
