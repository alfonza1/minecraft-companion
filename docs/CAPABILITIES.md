# Current capabilities and limitations

Automated/unit checks, local survival gameplay and real Realm gameplay are different evidence levels. This is a working but bounded teammate.

| Area | Works now | Still limited or unavailable |
| --- | --- | --- |
| Connection | Licensed Microsoft device-code login, encrypted cache, Realm choice, native26.3 adapter and reconnect gates | Future/unknown protocols and unvalidated newer materials are gated. Many advanced behaviors remain untested on the actual Realm. |
| Source analysis | Public YouTube video/audio adapter with optional Gemini key; actual Codex analysis of uploaded sampled video frames/screenshots; timestamped evidence and material lists | Live Gemini inference awaits a user key. Private/unlisted/restricted videos may be inaccessible. Sampling misses details. No guaranteed exact hidden-block reconstruction, local soundtrack transcription or complete tutorial coverage. |
| Reconstruction | Evidence-driven same-structure blueprint, source dimensions/palette, bounded procedural expansion, 3D preview and versioned materials | Model interpretation needs review. Known reported dimensions are enforced; tutorial vs blueprint item differences are shown. Preview currently approximates special shapes as cubes. Maximum50,000placements,128blocks/axis and262,144cells volume. A complete authorized schematic remains the strongest source for exact copying. |
| Construction | Approved cubes, dry stairs/slabs (including doubles), paired closed doors, oriented logs/pillars, fences/panes; doors-last access, exact verification and checkpoint resume. Prepared automatic worksites add grounded ramps, perimeter platforms and braces, then remove acknowledged scaffolds. | Automatic access is bounded to32×16×32 and512temporary blocks in clear observed space. It cannot guarantee access to every interior/roof. No terrain clearing, destructive repair, general site selection, waterlogging, powered/open doors, trapdoors or arbitrary decorations. Preview approximates shaped blocks as cubes. Realm construction remains untested. |
| Build supplies | Prepares bounded phase stock, reserves batches, withdraws approved chest materials/plain replacement tools, crafts repeated real recipes, optionally gathers oak/spruce/birch logs and approved-area cobblestone/dirt/sand within64blocks, creates a workbench and resumes placement. Supports respecting shares or covering the user's remainder; worksite extras are separate. | No furnace/stonecutter production, arbitrary resource acquisition or replacement-tool crafting during builds. Poor health/food, night, hostile mobs, full inventory or unreachable sources stop with a checkpoint. Tree recognition uses soil/canopy and known protected sites, not omniscient ownership. Chest stock is observed during transfers. Named/enchanted items and rare recipe ingredients remain protected. |
| Materials | Placement/item/raw counts, versioned crafting and available local furnace/stonecutter recipes, separate unresolved fuel/temporary supplies | Missing recipes/variants and fuel scheduling remain explicit. Shared project chest stock is not automatically allocated into project progress. |
| Shared gathering | Independent shares, common-material50/50 split, unsupported materials assigned to human with reasons, spoken/persistent supply requests, explicit expanding surface searches up to256 blocks with pre-trip loot deposits, food/daylight reserves and persistent return routes, manual overrides/user counts | Assigned automatic project gathering supports oak/spruce/birch logs. Other approved mining/farming skills are separate requests. The app cannot know your inventory. Open-ended voice reassignment remains limited. |
| Survival | Deterministic eating/retreat/defense, bounded gathering/crafting, adult-animal hunting, approved mature crop tending/replanting, owned-food cooking, automatic Home/spawn chest creation/expansion, reachable terrain scouting, food searching with basic hunting-gear preparation, storage and useful idle stock targets | Food scouting is bounded and respects wild-animal protections. No farm creation/expansion, reliable cave/branch mining, general furnace manufacturing, villager trading, full armor upgrades or Nether/End progression. No guarantee of survival or loot recovery. |
| Initiative | Approved food/storage/resource/scouting priorities and return to interrupted work | Stock-target idle work is not unrestricted strategic play. It waits when unsafe/unprepared. No complete bodyguard/guard coordination. |
| World knowledge | Loaded surroundings, own inventory, observed chests and remembered/user-reported locations | No remote Realm omniscience, unseen inventory knowledge, global ore map or guaranteed ownership of unmarked animals/items. |
| Voice/models | Warm local speech, sentence audio streaming, voice choices, global Windows PTT, interruption and separate conversation/work models with shared current context | Nonzero latency; validated model reply required before speech, no provider-token streaming. Physical devices need user validation. Claude needs subscription sign-in; OpenCode needs its configured provider/server. Source reconstruction currently requires Codex as work provider. |
| Memory/data | Persistent tasks/checkpoints/notes, recent/relevant context, backup/export | Unlimited-history summarization, full project/config import, general memory editing UI and player inventory companion remain unfinished. |
| Formats and browsing | Complete JSON and Sponge schematic imports; explicit YouTube reference search | No Litematica or legacy MCEdit import. General conversation does not have an unrestricted/current-information web research provider. |

The compact list is also available in **Companion → Current capabilities and limits**. Source analysis does not remove construction gates or grant server permissions.
