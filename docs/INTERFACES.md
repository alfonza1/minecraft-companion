# Implementation contracts

API binds 127.0.0.1:4365 and serves dashboard production dist. All mutations are JSON POST with a same-origin guard; GET /api/state returns State and WS /api/events sends {type:'state',state}. UI uses relative /api paths. No fake live data. Missing world values are null. API responses errors {error:string} with 4xx/5xx.

State shape (all fields present):
```
{state:'DISCONNECTED'|'PAUSED'|'ACTIVE'|'BUSY'|'ERROR', connection:{status:string,username:null|string,realmId:null|number,version:null|string,error:null|string,reconnectAttempt:number},auth:{status:string,username:null|string,device:null|{verificationUri:string,userCode:string,expiresAt:string}},realms:Realm[],world:null|{observedAt:string,position:{x,y,z},dimension:string,health:number,food:number,oxygen:number,experience:object,inventory:Item[],equipment:object,nearbyPlayers:object[],nearbyEntities:object[],timeOfDay:number},currentTask:null|object,tasks:object[],projects:object[],memories:object[],conversation:{id,role:'user'|'companion',text,at}[],usage:{requests:number,inputTokens:number,outputTokens:number,cachedInputTokens:number,billingCost:null},settings:object,voice:{available:boolean,status:string,error:null|string},logs:{at,level,message}[]}
```
Item {slot,name,displayName,count,type,stackSize,durabilityRemaining?:number}. Realm {id,name,owner,state,remoteSubscriptionId?,activeVersion?} (no credentials). Settings {realmId:null|number,playerName:string,autonomy:'instructions'|'helpful'|'independent',combat:'retreat'|'defend',followDistance:number,alertFrequency:'quiet'|'normal',model:string,maxRequestsPerHour:number,maxInputTokens:number,voice:{enabled:boolean,handsFree:boolean,speed:number,volume:number,inputDevice:string,outputDevice:string}}.

Core endpoints: GET /api/state, GET /api/health; POST /api/auth/connect {} (returns immediately and publishes device flow), POST /api/realms/refresh {}; POST /api/settings partial validated settings; POST /api/control {command:'start'|'pause'|'resume'|'stop'|'cancel'|'emergency'|'disconnect'}; POST /api/tasks {tool:string,args:object} explicit validated survival tools, POST /api/conversation {text:string}; POST /api/memories {label:string,value:string}; POST /api/memories/delete {id:string}.

Build module: services/build-planner/index.js exports registerBuildRoutes(app,context) and helpers. Context {store,runtime,publish}; store.get(collection) returns array, store.put(collection,record) upserts id, store.delete(collection,id), store.settings(), store.updateSettings(partial), runtime.snapshot(), runtime.execute(tool,args), runtime.isActive(), runtime.bot (nullable), runtime.actions (nullable), runtime.on(event,handler). Context publish() broadcasts state. Build routes prefix /api/projects: GET /api/projects, POST /api/projects (create {name,version,blueprint?}), POST /api/projects/:id/blueprint {blueprint}, POST /api/projects/:id/approve {}, POST /api/projects/:id/split {aiPercent:number}, POST /api/projects/:id/progress {material,owner:'user',quantity}, POST /api/projects/:id/build {origin:{x,y,z}}, POST /api/projects/:id/references (JSON text/YouTube URL or bounded multipart upload). Actual blueprint {version:string,dimensions:{x,y,z},blocks:{x,y,z,name:string,properties?:object,section?:string}[],provenance:'schematic'|'reconstructed'|'estimated',uncertainties:string[]}. Project includes id,name,blueprint,approvedRevision,revision,materials,assignments,checkpoint,references,status. Agent may extend and document routes; coordinate changes.

Speech module: services/voice/index.js exports registerVoiceRoutes(app,context), getVoiceStatus(), stopVoice(). STT POST /api/voice/transcribe audio multipart => {text}, TTS POST /api/voice/speak {text,speed} => audio/wav, GET /api/voice/status. Browser audio lives apps/desktop-voice with React integration hook exported for dashboard. Browser must stop tracks/playback on PAUSED/DISCONNECTED/ERROR, barge-in cancels speech and POST control cancel; microphone activation is explicit. Local Python worker subprocess only; recordings not retained.

Orchestrator module: services/agent-orchestrator/index.js exports createOrchestrator({runtime,store,publish}) returning {respond(text):Promise<string>,cancel():Promise<void>,usage:object,close():Promise<void>}. Core runtime calls cancel on pause/stop and routes /conversation to respond. No model loops. Codex supported CLI/app-server/SDK only; restrict tool execution outside validated Minecraft action plan, no shell/FS/network tools. Ordinary questions never call game tools. Active state gates before and after awaits. Lifetime cleanup mandatory. Store conversation/messages and usage with supplied store. Runtime uses EventEmitter; events 'pause','stop','disconnect' can additionally hook cleanup.

Store records backed by SQLite document table(collection,id,json), settings single document. No access tokens in app state/database/API. All assigned agents own their directories and tests only; parent owns root manifest, integration, README, runtime/auth/API/store.
