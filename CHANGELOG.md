# Changelog

## 0.3.0-alpha.1 — Your companion, across the adventure

- Redesigned the public website and 16-screen local workspace around a gaming
  companion: real activity, missions, inventory, resources, conversation and help.
- Added persistent, revision-checked assistance decisions and task ownership.
- Separated raw ingredients from placements, protected resource reservations and
  credited observed construction without inventing who gathered consumed supplies.
- Added a companion profile, explicit behavior modes and opt-in proactive remarks.
  Saved moments reference existing conversation or completed-work records; memory
  can be disabled, exported or deleted.
- Added a versioned game-observation adapter and a non-playable strategy fixture.
  Minecraft Survival remains the only playable integration.
- Added ordered live snapshots, heartbeat recovery, responsive browser checks,
  extension documentation and a real disconnected workspace screenshot.

Experimental prerelease. Existing account, provider, voice and local storage paths
are preserved. No claims of human-level play, a second game or exact reconstruction
of unseen video geometry.

## 0.2.0-alpha.1 — Waypoint experimental platform release

- Separate static public website and original Waypoint identity.
- Local Ollama provider with structured action validation and reported usage.
- Model selection in guided setup; portable core installer and support matrix.
- Versioned observation extension contract with a working inventory summary.
- Reproducible deterministic evaluation report, contributor guides and CI.
- Existing Minecraft Companion runtime, data identity and launcher preserved.

This is a prerelease-quality platform foundation, not a claim of unattended
survival competence or full macOS/Linux desktop support.
